Lima level, dua lapis soal untuk setiap perintah. Kenali fungsinya, lalu tulis cara pakainya. Salah? Tenang, ada pembahasannya.

Siap masuk dojo?

Isi nama dan kelasmu untuk memulai. Setelah selesai, hasil latihan bisa diunduh sebagai CSV.

Tiap perintah bernilai 2 poin: 1 untuk paham fungsi, 1 untuk mengetik sintaksnya.

01 / PAHAMI FUNGSINYA

Buat apa perintah ini?

02 / COBA KETIK

Unduh hasil dan detail jawabanmu sebagai file CSV.

Ini latihan sintaks, bukan terminal Linux sungguhan. Di terminal asli, pakai --help atau man untuk mencari bantuan; Tab membantu melengkapi ketikan dan panah atas mengulang perintah.

Hasil latihan dapat diimpor ke Google Sheets dari file CSV. Jika ingin pengiriman otomatis dari GitHub Pages, deploy Apps Script sebagai Web App terlebih dahulu, lalu tambahkan URL Web App ke kode sebelum mengaktifkannya.
